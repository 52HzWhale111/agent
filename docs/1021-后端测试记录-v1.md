## 实际启动与脚本检查

1. 执行 `scripts/manage.py init-db --demo`，实际导入60知识点、20案例、18选择题、3演示账号、45条记录及4个图版本。
2. 执行 `scripts/manage.py export`，实际生成OpenAPI及SQLite/PostgreSQL初始SQL。静态契约有21个HTTP操作，其中包含健康检查。
3. 将导出的SQLite SQL在独立空内存数据库完整执行，得到准确六张表。
4. 实际启动uvicorn并经HTTP访问，健康检查为ok，知识点总数60，demo_student有3张逻辑图，类图最新版为v2且有4个节点；Swagger页面HTTP 200。
5. 停止该测试服务进程，再重新启动，不重新导入数据；同一类图仍为v2、4节点，持久化检查通过。
6. 为提交 PR 准备的独立检出目录仅加入业务代码、文档与结构化种子快照，不重复提交知识工程的43个原资料文件；在该目录重新执行全部测试、init-db --demo和export，均成功。

测试过程中修复的问题：SQLite读回DateTime会丢失时区，导致注册和后续登录中同一created_at字段表示不一致。现在响应模型将来自SQLite的UTC时间补齐时区，注册与再次查询结果一致，回归通过。
