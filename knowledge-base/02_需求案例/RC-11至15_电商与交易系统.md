# 需求案例集：电商与交易系统（RC-11 至 RC-15）

## RC-11 简易购物车系统
- **背景**：电商网站基础的购物车功能。
- **角色**：买家。
- **功能需求**：加入购物车、修改数量、删除商品、计算总价（含折扣）。
- **非功能需求**：金额计算精度需精确到小数点后两位；价格实时更新。
- **主流程**：选购商品 -> 加入购物车 -> 修改数量 -> 勾选结算 -> 计算总金额。
- **异常流**：1. 商品已下架（购物车置灰提示）；2. 库存不足（修改数量失败）；3. 优惠券不可用。
- **标准答案要点**：需考虑商品失效状态；需明确总价计算规则（包邮、满减）。

## RC-12 外卖点餐系统
- **背景**：用户在线点餐，骑手配送。
- **角色**：顾客、商家、骑手。
- **功能需求**：浏览菜单、下单支付、商家接单、骑手抢单/派单、状态追踪。
- **非功能需求**：订单状态实时推送给用户；支持高并发下单。
- **主流程**：点餐 -> 支付 -> 商家接单 -> 骑手接单 -> 送达。
- **异常流**：1. 超时未支付（自动取消）；2. 商家拒单（原路退款）；3. 无骑手接单（系统调度或用户取消）。
- **标准答案要点**：订单状态机复杂（待支付、待接单、配送中、已完成、已取消）。

## RC-13 校园二手交易平台
- **背景**：学生出售和购买闲置物品。
- **角色**：卖家、买家、平台管理员。
- **功能需求**：发布商品、搜索商品、私信沟通、下单购买。
- **非功能需求**：禁止发布违规违禁物品。
- **主流程**：卖家发布 -> 买家浏览 -> 沟通 -> 线下/线上交易。
- **异常流**：1. 商品已售出（标记下架）；2. 发布违规词（触发拦截）。
- **标准答案要点**：需有敏感词过滤机制；商品上下架状态管理。

## RC-14 酒店预订系统
- **背景**：顾客在线预订酒店房间。
- **角色**：顾客、前台、酒店管理员。
- **功能需求**：按日期查空房、预订支付、入住、退房、保洁状态更新。
- **非功能需求**：房态数据实时同步，防止“一房多卖”。
- **主流程**：选日期 -> 选房型 -> 支付 -> 预订成功 -> 前台办理入住。
- **异常流**：1. 房间被抢订（支付时提示已无房）；2. 超时未入住（保留或取消）；3. 房间设施损坏（扣除押金）。
- **标准答案要点**：库存扣减（防超卖）；房态流转（空闲、预订、入住、打扫）。

## RC-15 健身房会员管理系统
- **背景**：健身房管理会员卡和课程。
- **角色**：会员、前台、教练。
- **功能需求**：办卡充值、约课、签到消耗课时、查看消费记录。
- **非功能需求**：会员卡防伪（实名认证）。
- **主流程**：会员约课 -> 上课签到 -> 系统扣减1次课时。
- **异常流**：1. 课时余额不足（拒绝约课）；2. 教练请假（系统自动取消并退回课时）；3. 会员卡过期。
- **标准答案要点**：课时扣减的原子性；教练临时取消的补偿机制。
