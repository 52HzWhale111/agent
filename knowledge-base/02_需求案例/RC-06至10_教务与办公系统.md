# 需求案例集：教务与办公系统（RC-06 至 RC-10）

## RC-06 会议室预约系统
- **背景**：公司内部员工预约会议室开会。
- **角色**：员工、行政管理员。
- **功能需求**：查看空闲会议室、预约、取消预约、审批大型会议。
- **非功能需求**：时间冲突检测必须准确，且页面需实时刷新状态。
- **主流程**：选日期和时间 -> 选会议室 -> 提交预约 -> 系统锁定该时段。
- **异常流**：1. 时段冲突（提示已被占用）；2. 超出预约最大时长（拒绝）；3. 超过50人的会议需管理员审批。
- **标准答案要点**：并发预约的冲突检测；大会议室需要审批流。

## RC-07 企业OA请假审批系统
- **背景**：员工请假需要走线上审批流。
- **角色**：员工、部门主管、HR。
- **功能需求**：提交请假单、主管审批、HR备案、销假。
- **非功能需求**：审批流程状态不可篡改，所有操作需留存操作日志。
- **主流程**：员工提交申请 -> 主管审批同意 -> HR确认 -> 状态变为已生效。
- **异常流**：1. 主管驳回（需填写驳回理由）；2. 超过3天未审批（系统自动提醒）。
- **标准答案要点**：状态机流转（待审批、已通过、已驳回、已撤销）；角色权限隔离。

## RC-08 在线考试系统
- **背景**：学校或培训机构进行线上测试。
- **角色**：考生、监考教师。
- **功能需求**：登录考试、答题、交卷、自动判分、主观题人工批改。
- **非功能需求**：断网自动保存答案；防切屏作弊检测。
- **主流程**：进入考场 -> 倒计时开始 -> 答题 -> 点击交卷 -> 客观题立刻出分。
- **异常流**：1. 考试中掉线（重连后可恢复答题进度）；2. 超时未交卷（系统强制提交）。
- **标准答案要点**：断网容灾机制；超时强制交卷；防作弊机制。

## RC-09 企业固定资产管理
- **背景**：公司内部管理电脑、桌椅等固定资产。
- **角色**：普通员工、资产管理员。
- **功能需求**：资产入库、领用、归还、报废、按部门统计。
- **非功能需求**：每个资产需有唯一的二维码/条形码。
- **主流程**：扫码领用 -> 系统绑定员工ID -> 状态变为“使用中”。
- **异常流**：1. 资产已被占用（拒绝领用）；2. 资产损坏报废（需管理员审核）。
- **标准答案要点**：资产状态流转（在库、使用中、维修中、报废）；唯一标识。

## RC-10 员工考勤打卡系统
- **背景**：记录员工上下班时间。
- **角色**：员工、考勤专员。
- **功能需求**：GPS打卡/人脸打卡、异常申诉、月度考勤统计。
- **非功能需求**：防止虚拟定位打卡；高并发打卡（早高峰）不崩溃。
- **主流程**：员工在指定范围打卡 -> 系统记录时间 -> 生成考勤记录。
- **异常流**：1. 不在打卡范围（拒绝打卡）；2. 忘记打卡（走申诉流程补卡）。
- **标准答案要点**：防作弊（定位伪造）；申诉流程；统计规则（迟到、早退）。
