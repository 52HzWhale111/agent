# 需求案例集：娱乐与基础设施（RC-16 至 RC-20）

## RC-16 在线视频播放平台
- **背景**：类似于B站的视频观看平台。
- **角色**：观众、UP主、审核员。
- **功能需求**：上传视频、审核、播放、点赞投币、弹幕、收藏。
- **非功能需求**：视频播放流畅（CDN加速）；弹幕实时发送且不卡顿。
- **主流程**：UP主上传 -> 审核通过 -> 观众点击播放 -> 发送弹幕。
- **异常流**：1. 视频失效/被删（提示404）；2. 弹幕包含违规词（被屏蔽）；3. 网络缓冲（显示加载圈）。
- **标准答案要点**：多分辨率支持；违规内容审核机制。

## RC-17 物流追踪系统
- **背景**：快递公司内部及面向用户的包裹追踪。
- **角色**：寄件人、快递员、网点管理员。
- **功能需求**：寄件下单、揽收、中转记录、派送、签收、轨迹查询。
- **非功能需求**：轨迹信息更新延迟<10分钟。
- **主流程**：寄件 -> 快递员揽收 -> 扫码中转 -> 派送 -> 签收。
- **异常流**：1. 包裹丢失（触发理赔流程）；2. 地址错误（打回网点）；3. 拒收（原路退回）。
- **标准答案要点**：状态节点清晰；异常件处理流程。

## RC-18 停车场收费系统
- **背景**：商业综合体地下停车场。
- **角色**：车主、保安/收费员。
- **功能需求**：车牌识别入场、计费、扫码缴费、抬杆出场。
- **非功能需求**：车牌识别准确率>99%；断网时能离线计费。
- **主流程**：入场抓拍车牌 -> 记录入场时间 -> 出场计算时长和费用 -> 缴费 -> 抬杆。
- **异常流**：1. 识别错车牌（人工纠正）；2. 逃费冲卡（记录黑名单）；3. 断网（本地保存数据，联网后同步）。
- **标准答案要点**：计费规则（阶梯收费）；断网容灾。

## RC-19 共享单车App
- **背景**：校园或城市共享单车租赁。
- **角色**：用户、运维人员。
- **功能需求**：扫码开锁、骑行计费、关锁结费、故障报修、查找附近车辆。
- **非功能需求**：定位准确；蓝牙开锁低延迟。
- **主流程**：扫码 -> 开锁 -> 骑行 -> 关锁 -> 自动扣费。
- **异常流**：1. 车辆已损坏（提示报修）；2. 关锁失败（提示确认或手动结束）；3. 不在停车区（收取调度费）。
- **标准答案要点**：开锁/关锁状态同步；计费规则；电子围栏技术。

## RC-20 智能家居控制系统
- **背景**：通过手机App控制家里的智能设备（灯、空调、窗帘）。
- **角色**：家庭成员。
- **功能需求**：设备开关控制、定时任务、场景模式（如离家模式）、设备状态同步。
- **非功能需求**：控制指令响应<1秒；断网时设备需保持原有状态。
- **主流程**：打开App -> 选择设备 -> 点击开关 -> 发送指令 -> 设备响应。
- **异常流**：1. 设备离线（提示设备不在线）；2. 网关掉线（本地局域网控制失效）；3. 权限冲突（管理员修改了密码）。
- **标准答案要点**：设备状态同步（心跳机制）；定时任务可靠执行。
