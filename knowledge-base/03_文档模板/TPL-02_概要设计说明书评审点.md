# TPL-02 概要设计说明书评审点

**依据**：教材第12章体系结构设计、第13章构件级设计，PDF第152-190页；课件8.pdf、课件9.pdf。
**老师会看的核心结构**：引言 -> 总体架构设计（架构风格/技术选型） -> 模块划分与接口 -> 数据库设计（E-R图/表结构） -> 异常处理机制。

**文档评审评分点（Agent查错清单）：**
1. **总体架构**：是否说明了系统的总体架构风格（如分层架构、C/S或B/S模式）。
2. **模块划分**：模块拆分是否合理，是否符合高内聚低耦合原则。
3. **接口设计**：模块间的内部接口定义是否清晰（输入参数、输出结果、异常码）。
4. **数据设计**：数据库表结构、E-R图是否与需求模型一致，是否定义了主外键。
5. **异常处理**：系统级的异常和错误处理机制是否设计完备（不能只写正常情况）。
6. **设计图一致性**：设计类图、时序图是否与需求用例图对得上。
7. **技术选型**：是否说明了关键技术栈选型及其理由（如为什么用MySQL不用Redis）。
