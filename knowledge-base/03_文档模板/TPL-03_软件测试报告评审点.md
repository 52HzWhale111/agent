# TPL-03 软件测试报告评审点

**依据**：教材第17章软件测试策略、第18章传统应用测试，PDF第246-279页；课件14.pdf、课件15.pdf。
**老师会看的核心结构**：概述（目的/环境） -> 测试执行情况（范围/用例统计） -> 缺陷统计与分析（分级/遗留问题） -> 测试结论。

**文档评审评分点（Agent查错清单）：**
1. **测试环境**：是否明确说明了测试的软硬件环境和版本号。
2. **测试范围**：是否覆盖了需求规格中的所有核心功能和异常流。
3. **用例执行统计**：是否列出了测试用例总数、通过率、失败率。
4. **缺陷统计与分级**：是否有缺陷列表，包含严重程度（P0致命-P3轻微）和当前修复状态。
5. **覆盖率数据**：是否包含代码覆盖率（如语句覆盖、分支覆盖）或需求覆盖率数据。
6. **遗留问题**：未修复的缺陷是否说明了影响范围和规避方案。
7. **测试结论**：给出明确的结论（是否允许发布上线，不能模棱两可）。
